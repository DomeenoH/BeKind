### 关键改动
1. **动效令牌**：`--ease` 换成 `cubic-bezier(0.23,1,0.32,1)`，新增 `--ease-out / --ease-in-out / --ease-drawer` 与 `--dur-press/fast/base/slow`。所有 transition 时长指向 token。
2. **按压反馈**：卡片 `.995`、翻页卡 `.99`、随机按钮/图标按钮 `.97/.94`；触屏 `-webkit-tap-highlight-color: transparent`。
3. **hover 门控**：卡片抬升、印章摆正、翻页箭头位移全部进 `@media (hover:hover) and (pointer:fine)`，避免触屏残留 hover。
4. **性能**：阅读进度改 `scaleX`（原来改 width）、分享骨架条改 `translateX`（原来改 left）。
5. **页头**：滚动 0–120px 时伪元素 shadow 的 opacity 用 `scroll(root)` 时间轴驱动（无 JS）；`prefers-reduced-transparency` 去毛玻璃。
6. **分享弹窗**：`@starting-style` + transition 做进场，桌面 scale(.985)+10px 淡入 220ms，移动端从底部 `translateY(100%)` 320ms 抽屉曲线；遮罩同步压暗；出图从骨架切图有 220ms 淡入。
7. **跨页 View Transition**：`@view-transition { navigation: auto }` + root 交叉淡入 200ms，reduced-motion 关闭。
8. **CSS 去重**：文件尾部有 ~300 行完全重复的卡片/印章规则（同一个 `.law-card` 被声明 4 次）、`.card-quote`/`.card-top`/`.contents`/`.home-intro-grid` 全是死样式 —— 全部清掉，卡片一节改成唯一一份终版。
9. 细节：`text-wrap: balance` 到 display/section/law 标题；全局 `:focus-visible` 去掉 `border-radius: 4px`（否则圆按钮焦点环变方）。

### 踩到的坑（重要）
- `body { overflow-x: hidden }` 会把 body 变成滚动容器，`view()` 滚动时间轴认错滚动源 → 卡片永远停在 opacity 0。已改 `overflow-x: clip`。
- 因此**放弃**了索引卡滚动揭示（`animation-timeline: view()`）：无头环境无法验证，一旦时间轴不跑就是整页看不见，收益风险不成比例。
- macOS 上 headless Chrome `--window-size` 有最小宽度（约 500px），390 截图会被裁；用 CDP `Emulation.setDeviceMetricsOverride` 才能真跑 390。
- 验收用 CDP 脚本（ws 直连 9333 端口）比 MCP 浏览器截图靠谱，后者固定超 10MiB 上限。
