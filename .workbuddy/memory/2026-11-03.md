## 分享卡 v2：html2canvas → Canvas 2D（下午）

- 起因：多米诺要迭代「图片生成」，当前卡片偏粗糙。审计发现根因是渲染模型：固定 600×800 + 垂直居中 → 短卡上下各 130px 空洞；84 字硬切 → `make-it-easy-to-reply` 被切在「…点导出…」；每卡 lucide 图标代替品牌双气泡；无比例选择；data URL 下载在 iOS 不可靠。
- 方案：`lib/poster-layout.ts`（纯排版，注入 measure）+ `lib/poster-render.ts`（Canvas 2D）+ 重写 `ShareActions.astro`。3:4 = 540×720@2x（带摘要），1:1 = 540×540@2x（摘录版，无摘要、无标签行）；两版共用同一布局函数。
- 关键规则：全卡单一文字左边界 x=44，×/✓ 挂页边 x=26；标题 46/40（1:1 40/34）；引文配对档 P0 32/28 → P4 18/17（1:1 最小 19/18）；块高按墨迹 `size+(lines-1)*size*lh`；章节线位置按「上方留白 = 下方留白」反解（不是固定对半分）。
- 内容层：引文取 `line.html` 渲染后的文本（`[图片：…]`/`[语音…]`），整句括号旁白丢弃；删除 clampText；陈述式从 `specialHtml` 解析 3 条 li。
- 交互：弹窗同步打开；200ms 后纸块 + 1px 不确定进度线；比例切换静默重绘；两比例缓存 Blob；pagehide 只 revoke URL；微信=复制链接+长按提示；支持 Web Share/下载/复制图片；文件名 `BeKind-01-标题-3x4.png`；错误分 stale/offline/render。
- 验证：66 条 × 2 比例全过（1080×1440 / 1080×1080），首屏渲染中位 85ms；二维码 Vision 解码通过；`npm test` 32 passed；`npm run build` 通过；`tsc --noEmit` 通过。html2canvas 已移除（chunk 37KB，含 qrcode）。
- 坑：
  - 原生 `<dialog>` UA 有 `max-width: calc(100% - 6px - 2em)`，手机 `width:100%` 会被压到 352；必须 `max-width:none`。
  - 站点 `scroll-behavior:smooth`，关闭弹窗恢复 scrollY 要临时改 `auto`；Playwright `click()` 会自动滚到按钮，测滚动恢复要用 `evaluate(click)`。
  - Canvas 不要用 `ctx.roundRect`（Safari 16 前没有），用 arcTo 画圆角。
  - `crypto`/长任务：Playwright 全量 66×2 不要每页截图，否则 OOM/SIGTERM；分批换 page。
  - 本机 `grep` 的 BRE 交替仍不可靠，用 Grep 工具或 node。
